# IDEAS — UX и технические улучшения

Замечания, собранные при работе над поведенческим слоем (Волна 1). Не реализованы — ждут подтверждения.

## UX

- **Английские тексты в `src/texts.ts`:** `setupDone`, `notGroup`, `notAdmin`, `joinSuccess`, `leaveSuccess` и другие — на английском, хотя весь UI на русском. Стоит перевести для консистентности.
- **`streakLabel(0)` = "серия сброшена":** Звучит как наказание. Вариант: "новый старт" или "день первый" — фрейминг fresh start вместо потери.
- **Пустое окно (никто не ответил):** Сейчас при закрытии окна без ответов удаляется приглашение. Если никто не ответил за весь день — можно отправить мягкий итог вместо тишины ("Тихий вечер. Завтра снова.").
- **Первый запуск бота в группе:** После `/setup` нет объяснения участникам, что делать. Первое окно можно сопроводить коротким "как это работает" (один раз).

## Техника

- **`@grammyjs/conversations`** в `dependencies`, но нигде не используется (SPEC §10.2 подтверждает). Можно удалить.
- **Дублирование `getMemberCheckinHistory`:** Функция определена в `src/services/summary.ts` и почти идентичная в `src/services/highlights.ts` (`getMemberHistory`). Можно вынести в общий модуль.
- **LLM-наблюдаемость:** При `LOG_LEVEL=debug` логируются полные payloads. В production нет метрик (время ответа, количество fallbacks, ошибки). Стоит добавить счётчики или structured logging.
- **Поля-заглушки из SPEC §3.2:** `nudge_enabled` (column exists, no logic), `checkins.note` (column exists, unused), `members.timezone_override` (stored, not applied). Решить: подключать в Волне 3 или убирать из схемы.
